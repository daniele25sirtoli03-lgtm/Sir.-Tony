Informativa sulla privacy di Sir. Tony

Aggiornata il 09/11/2026.

Sir. Tony è un assistente personale ad uso privato. L'unico utente è il suo autore, Daniele.

Dati usati

Con il permesso dell'utente, Sir. Tony accede al suo Google Calendar (leggere, creare, spostare e cancellare eventi) e alla sua Gmail (leggere i messaggi, preparare bozze, spostare nel cestino). Ogni modifica richiede una conferma manuale.

Dove restano i dati

I dati restano sul computer personale dell'utente. Non vengono venduti, condivisi con terzi né usati per pubblicità o per allenare modelli di intelligenza artificiale.

L'uso delle informazioni ricevute dalle API Google rispetta le Google API Services User Data Policy, compresi i requisiti di uso limitato (Limited Use).

Revoca

L'accesso si può revocare in qualsiasi momento da myaccount.google.com/permissions.
